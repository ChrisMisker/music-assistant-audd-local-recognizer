# Audio Recognizer: AudD + Local Fingerprints v0.5.0

Experimental Music Assistant Audio Analysis provider for live AudioSources.

- Official MA AudioSource analysis opt-in (no core patch)
- Panako fingerprints via Audalign
- Deterministic 6.25% fingerprint density
- Persistent SQLite reference-window database
- AudD standard recognition fallback
- Native support for MA f32le/32-bit live PCM and s16 PCM

This is an experimental development build intended for Music Assistant Nightly 2.11 dev builds containing AudioSource analysis support.
